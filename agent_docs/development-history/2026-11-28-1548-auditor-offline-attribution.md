# Уточнение методологии и исследование офлайн-атрибуции

- Обновлён контракт ручного CRM-среза и утверждённая методология расчёта
  валовых, квалифицированных и мусорных лидов.
- Сопоставлены Reporting API, Logs API, Management API и интерфейс Метрики.
  Описаны отдельные схемы рекламной атрибуции и обогащения после CRM-среза.
- Обновлён синтетический эталон с дублями, неоднозначным ClientID и сигналом
  квалификации после выгрузки.
