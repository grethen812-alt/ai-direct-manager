# Границы отчётов первой фазы

## Изменения

- Общий дедлайн отчётов составляет 90 секунд. Повторные запросы Директа ограничены паузой до 5 секунд.
- Добавлены проверка форматов и лимиты периода, строк и байтов. Превышение лимита и неполный
  ответ Метрики дают явную ошибку.
- Синтетический сервер запускается командой `yandex-ads-mcp-phase1-demo`. Она автоматически
  подставляет тестовые данные и запускает тот же профиль через `stdio`.

## Проверка

- Повторный прогон покрывает дедлайн, интервалы, границы объёма, схемы данных и отсутствие
  частичных результатов.
- Для туннеля сохраняется прежний интерфейс `stdio`. Команда демо и ожидаемые ответы описаны
  в [инструкции](../guides/phase1-readonly.md#синтетический-сервер-и-secure-mcp-tunnel).
