# Первая фаза AI Direct Manager

- **Дата** — 2026-11-25
- **Статус** — реализовано
- **Основание** — утверждённый технический аудит и требования владельца к первой фазе.

## Критерии приёмки

1. Отдельная команда запуска публикует только восемь инструментов чтения Директа и Метрики.
2. Неподдерживаемые имена инструментов и аргументы блокируются до HTTP. Подмена кабинета,
   счётчика, адреса или метода проверяется независимо на уровне исходящего запроса.
3. Профиль исключает операции с локальными файлами. Ошибки возвращаются без аргументов,
   значений переменных окружения и ответов API.
4. Пакет собирается, зависимости зафиксированы, есть тесты `stdio` и HTTP с синтетическими
   ответами. Штатные проверки исходного сервера проходят.
5. Документация запуска и проверки написана по-русски. Изменения вносятся через PR из
   `feature/phase-1-readonly`.

6. Отчёты обоих API имеют сквозной дедлайн, ограниченный период, объём и число строк.
   Некорректный или неполный ответ возвращается как ошибка без частичных данных.
7. Синтетический сервер запускается одной командой с автоматически заданными тестовыми
   параметрами и сохраняет транспорт `stdio` для частного туннеля.

## Границы

В этой итерации проверка выполняется офлайн. Интеграция с реальными кабинетами, публичное
развёртывание, Yandex Direct Skill и n8n отложены.

## Проверка

Критерии 1–3 и 7 покрывает `test_phase1_readonly.py`. Отчётный профиль проверяет `test_phase1_reports.py`. Совместимость и сборку проверяет
`.github/workflows/test.yml`. Команды запуска и переменные описаны в
[инструкции профиля](../guides/phase1-readonly.md).
