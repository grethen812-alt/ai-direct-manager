# Разделение экспертных ролей в AI Performance Manager

## Статус

Предложено. Требует архитектурного ревью.

## Контекст

Профиль Директа и Метрики уже работает через частный плагин в браузерном Codex.
Будущим ролям нужны разные права, независимая оценка результатов и общий
контекст, который можно перенести в другую задачу.

## Решение

На пилоте использовать управляющий сценарий и отдельные задачи экспертных ролей
в браузерном Codex. Контекст и доказательства передавать версионированными пакетами.
Разграничение задавать в подключениях и серверной авторизации.
Будущие операции записи поручать отдельному исполнителю после проверки
согласованной версии плана.

## Альтернативы

- Единый чат с двумя ролями сокращает число переходов, но делит инструменты
  и историю и затрудняет независимую оценку.
- Подагенты упрощают делегирование, когда подтверждена доступность в нужном
  интерфейсе. Наследуемые инструменты не задают техническую границу.
- Отдельный оркестратор пригодится при появлении требований к очередям,
  расписаниям или автоматическому исполнению с машинным контролем прав.

## Последствия

Начальный пилот использует действующую интеграцию. Потребуются согласованные
контракты, частное хранилище пакетов и проверка прав для каждого нового источника.
Автоматизация и выделение автономных агентов остаются дальнейшими решениями.
