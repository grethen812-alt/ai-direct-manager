# Отдельный MCP-профиль первой фазы

## Статус

Принято.

## Контекст

Основной сервер включает режим чтения по переменной окружения и определяет изменяющие
операции по имени. Профилю аналитики нужна обязательная изоляция, включая сетевой уровень.

## Решение

Добавить отдельную команду и отдельную регистрацию восьми инструментов. Использовать
существующие обработчики чтения. Проверять кабинет через `Clients.get` перед каждым
вызовом Директа и проверять маршрут, метод и область доступа перед отправкой HTTP-запроса.

## Последствия

Одна настройка соответствует одному кабинету Директа и одному счётчику Метрики.
Перед каждой операцией Директа выполняется дополнительный запрос идентификации.
Команда запуска основного сервера сохраняет прежний контракт.
