## Входные наборы

Тестовый продукт, один кабинет и счётчик, кампания C1, один отчётный интервал
1–2 ноября 2026 года. Ручная выгрузка CRM сделана 3 ноября. Все расходы
в одной тестовой валюте, с одинаковым учётом НДС.

| Связка | Объявление / креатив / посадочная | Показы | Клики | Расход |
| --- | --- | ---: | ---: | ---: |
| A | A1 / KA-v1 / PA-v1 | 2 000 | 60 | 6 000 |
| B | B1 / KB-v1 / PB-v1 | 2 000 | 120 | 2 400 |
| Кампания C1, отдельная сверка | — | 4 000 | 180 | 8 400 |

В CRM восемь уникальных ID и точный технический повтор L02.

| Лид | Ключ отправки | Стадия на дату выгрузки и основание связи |
| --- | --- | --- |
| L01 | F1 | Q1, доказаны C1 и A, браузер X1 |
| L02 | F2 | Q2, доказаны C1 и A. Строка технически повторяется |
| L03 | F3 | Ожидает уточнения, доказаны C1 и A, браузер X2 |
| L04 | F4 | Неизвестная стадия, доказаны C1 и B. ClientID отсутствует |
| L05 | F5 | Мусор, доказана только C1, браузер X3 |
| L06 | F6 | Архивная стадия, два кандидата по UTM, тот же браузер X3, источник не доказан |
| L07 | FT | Тестовая отправка |
| L08 | — | Бизнес-дубль L01 с собственным CRM-ID. Доказана только C1 |

В Метрике **7 достижений онлайн-цели формы**. Событийный эталон содержит
два разных события для F1, по одному для F2–F5 и одно для FT.
Страница входа L01 отличается от страницы отправки PA-v1.
У L06 нет подтверждения отправки. В отдельном наборе Вордстата
спрос по одной фразе в одинаковом регионе и срезе устройств — 1 000 → 800
за равные полные недели. Набор с другим регионом проверяет отбраковку среза.

## Офлайн-доказательства и отрицательные проверки

| Случай | Эталонное решение |
| --- | --- |
| X1 имеет два визита и один привязанный рекламный клик | Отдельный ключ F1 доказывает связь лида. Модель отчёта и основание выбора визита зафиксированы. Совпадение X1 само по себе не подтверждает объявление. |
| X3 имеет несколько визитов, два лида и несколько целей | Есть правдоподобные кандидаты на визит. Офлайн-цели без общего ключа не распределяются между лидами. L06 не приписывается к C1. |
| У L04 нет ClientID, есть подтверждённая связь по F4 | Он остаётся в валовых. Явное доказательство из другого источника сохраняет атрибуцию. |
| После среза по L03 пришёл сигнал с ключом исходного лида и утверждённой тестовой картой целей | В отдельном наборе отражается подтверждённое событие этапа со временем и источником. Исходная стадия и официальные KPI среза остаются прежними. |
| То же событие отправлено повторно с тем же стабильным ключом | Один аналитический сигнал. Если ключ отсутствует, повтор отмечается как возможный. |
| Цель до среза обнаружена после него | Сохраняются время события и время обнаружения. Сигнал не назван новым событием после среза. |
| Сопоставления нет из-за старого визита, невалидной цели или отсутствия данных | Указывается известная причина, иначе «недостаточно доказательств». Отсутствие офлайн-события не меняет квалификацию в CRM. |

## Ожидаемые результаты

- **Семь валовых лидов** после исключения тестового ID. L08 остаётся в валовых.
  Для C1 подтверждены шесть валовых, из них три для A, один для B, два только
  на уровне кампании. Покрытие до связки — **4/6**, до кампании — **6/7**.
- **Два квалифицированных** в C1, оба у A. Доля — **2/6 (33,3%)**,
  стоимость квалифицированного лида — **4 200**. В C1 **один мусорный лид**,
  доля — **1/6 (16,7%)**. CPL валовых C1 — **1 400**. Для B стоимость
  квалифицированного лида не рассчитана из-за нулевого знаменателя.
- Распределение показывает восемь категорий из тестового справочника,
  неизвестный L04 и архивный L06 отдельными строками. Рабочие лиды
  отсутствуют в расчётах. После среза по L03 виден сигнал, но число
  квалифицированных по выгрузке остаётся **2**.
- CTR A и B — **3%** и **6%**, CPC — **100** и **20**. Вывод о бизнес-результате
  использует квалифицированные лиды и раскрывает неполную атрибуцию.
  В дополнительном варианте сравнения рост CPL с 800 до 1 200 при изменении
  валовых 10 → 6 и квалифицированных 2 → 3 допускается при сопоставимых срезах.
- F‑01 показывает пять сопоставимых нетестовых заявок с доказательствами
  онлайн-отправки. Повтор цели для F1 и тест FT объясняют отличие агрегата.
  Для L06 вердикт — «не удалось проверить». Уровень входа и отправки
  не смешиваются. Спрос по сопоставимой фразе уменьшился на **20%**,
  причинность для динамики лидов не заявляется.

## Критерии прохождения

| Проверка | Условие приёмки |
| --- | --- |
| Снимок CRM | Один ID учитывается один раз. Тест, бизнес-дубль, неизвестная и архивная стадии обработаны по контракту без догадок. |
| Аналитические KPI | Все цифры воспроизводимы из входных наборов. Доля, CPL и CPQL используют согласованную область и знаменатели. |
| Атрибуция и обогащение | Кандидаты, степень доказательности, конфликт и отсутствие данных видны. Сигнал Метрики не переписывает Sheets и статус CRM. |
| F‑01 и полнота | Повтор цели отделён от дублирования строки. При пропусках, семплировании, конфликте или переполнении вывод ограничен. |
| Границы | Только синтетика, чтение и обезличенные ссылки на доказательства. |
