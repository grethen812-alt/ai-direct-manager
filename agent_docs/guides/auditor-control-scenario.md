# Синтетический контрольный сценарий Performance Auditor

**Статус — эталон для согласования.** Все значения вымышлены.
[Контракт данных](../specs/2026-11-28-auditor-data-contract.md)

## Входные наборы

Один тестовый продукт, один кабинет и счётчик, кампания `C1` и две версии связки.
Отчёты используют одну тестовую валюту и одинаковый режим учёта НДС.
Период закрыт с 1 по 2 ноября 2026 года включительно, срез CRM сделан 3 ноября.
У входных листов есть версии, признаки полноты и согласованный для теста
часовой пояс. Ключи и признаки допустимости заданы эталоном только для этого теста.

| Связка | Объявление / креатив / посадочная | Показы | Клики | Расход |
| --- | --- | ---: | ---: | ---: |
| A | `A1 / KA-v1 / PA-v1` | 2 000 | 60 | 6 000 |
| B | `B1 / KB-v1 / PB-v1` | 2 000 | 120 | 2 400 |
| Независимый синтетический итог кампании | `C1` | 4 000 | 180 | 8 400 |

CRM содержит восемь разных записей и один технический повтор строки L02.
Справочник отмечает исходный статус L04 как неизвестный. Срез не подтверждает
зрелость L03. Синтетические отметки «реальная», «тест» и «бизнес-дубль»
дают эталон количества для проверки. Определения рабочих и целевых заявок
и формулы воронки намеренно отсутствуют.

| CRM | Ключ отправки | Эталон связи и тип записи |
| --- | --- | --- |
| L01 | F1 | Реальная, кампания C1, связка A |
| L02 | F2 | Реальная, C1, связка A. Строка продублирована в выгрузке |
| L03 | F3 | Реальная, C1, связка A. Статус ещё не дозрел |
| L04 | F4 | Реальная, C1, связка B. Исходный статус не сопоставлен |
| L05 | F5 | Реальная, C1. Объявление и версии материалов не доказаны |
| L06 | F6 | Реальная в пилотной выгрузке. Два кандидата по UTM. Источник не подтверждён |
| L07 | FT | Тестовая отправка |
| L08 | — | Бизнес-дубль L01 по условию эталона |

В агрегате Метрики **7 достижений цели формы**. Событийный эталон содержит два
достижения с разными ID для F1, по одному для F2–F5 и одно для FT.
Два достижения F1 соответствуют одной заявке. Для L01 заданы отдельная страница
входа и версия страницы отправки PA-v1. Для L06 событийного доказательства нет.

В синтетическом Вордстате спрос по одной фразе в одном регионе и на одном
срезе устройств — **1 000 → 800 запросов** за две сравнимые полные недели.
Дополнительный набор с другим регионом служит отрицательным контролем.

## Ожидаемые результаты

- После удаления технического повтора остаются восемь CRM-записей. Эталон даёт
  шесть реальных заявок в общей выгрузке, из которых пять подтверждены для C1.
  Одна остаётся с неопределённым источником. Тест и бизнес-дубль показаны отдельно.
- Для C1 распределены три заявки связке A, одна связке B и одна остаётся
  на уровне кампании. Покрытие атрибуции до связки — **4/5 (80%)** среди
  подтверждённых заявок C1. Атрибуция до кампании — **5/6** в общей выгрузке.
- Для A и B CTR составляет **3%** и **6%**, CPC — **100** и **20**.
  Число подтверждённых заявок A выше. Расход на одну подтверждённую заявку
  составляет **2 000** для A и **2 400** для B. Для кампании — **1 680** при
  пяти подтверждённых заявках. Расчёты на уровне связки отражают неполное покрытие
  и не оправдывают категоричное отключение или масштабирование.
- F‑01 показывает пять сопоставимых заявок с доказательствами и объясняет,
  почему общие числа достижений и заявок различаются. Для сегмента с достаточным
  свидетельством возможен статус «корректно», для L06 — «не удалось проверить».
  Разница агрегатов сама по себе не доказывает сбой.
- Рабочие и целевые заявки и производные показатели обозначены «не утверждено».
  L03 и L04 показаны отдельно как незрелая и неклассифицированная записи.
- Спрос уменьшился на **20%** на сопоставимом срезе. Результат отмечен как
  контекст для проверки гипотезы, без утверждения о причине динамики заявок.

## Критерии прохождения

| Проверка | Условие приёмки |
| --- | --- |
| Воспроизводимость | Каждый итог связан с версией источника, областью, периодом, срезом и правилами. Повтор даёт ожидаемые числа и причины исключений. |
| Атрибуция и приоритет | Неопределённая заявка не попадает в C1. Кампанийная заявка не наследует объявление, креатив или страницу. Результативность оценивается по подтверждённым реальным заявкам, CTR служит диагностике. |
| F‑01 и неопределённость | Повтор цели, тест, технический повтор и бизнес-дубль различены. Страница входа отделена от страницы отправки. Статусы F‑01 обоснованы источником доказательства. |
| Контроль полноты | При пропусках, семплировании или несовместимом срезе отчёт раскрывает ограничения и блокирует затронутые сравнения. Нулевой знаменатель даёт «не рассчитано». Уникальные пользователи в перекрывающихся срезах не суммируются. |
| Профессиональные выводы | Отдельно показаны результативность, комплексная оценка и основания для дальнейшей проверки. Тексты, креативы и посадочные имеют свои критерии качества. Без версии материала оценка явно ограничена. |
| Границы доступа | Используются только синтетические наборы и чтение. При передаче результата используются обезличенные ссылки. Операции изменения и отправки отчёта не выполняются. |

Дополнительные варианты приёмки — противоречивый ключ F1 сразу на два разных
CRM-ID, изменившаяся версия формы, `limit: 1001`, неподтверждённая атрибуция и
новое синтетическое исследование ЦА. В последнем варианте аудитор начинает
с проверки уже работающих связок и обосновывает, что изменить и как измерить эффект.
